HOME SOC LAB - AUTHENTICATION SEQUENCE INVESTIGATION
====================================================

Investigation ID: LAB-INV-002
Date: 27 October 2026
Data source: evidence/sample-logs/sample-auth-suspicious-sequence.log
Environment: Local lab using fictional authentication logs
Status: Detection demonstrated; no real compromise established

1. OBSERVED EVENTS

Source IP: 192.0.2.75
Failed login attempts: 3
Successful login attempts: 1
Configured failure threshold: 3

The sample contains three failed password attempts followed by a
successful password login from the same source IP.

2. DETECTION RESULTS

Alert 1: Repeated failed logins from 192.0.2.75
Alert 2: Failed logins followed by a successful login from 192.0.2.75

Both alerts were generated by the local Python detection script.

3. INVESTIGATION ASSESSMENT

The sequence is worth investigating because repeated authentication
failures followed by a success may indicate a successful login after
repeated guessing attempts.

However, the sample is fictional training data. It does not establish
that a real account was compromised or that the activity was malicious.

4. RECOMMENDED ANALYST ACTIONS

- Verify the account and whether the successful login was expected.
- Review timestamps and surrounding authentication events.
- Check source IP reputation using approved threat-intelligence sources
  if investigating a real incident.
- Escalate according to the organisation's incident-response procedure
  if evidence supports suspicious activity.

5. VALIDATION

Automated test:
test_failures_followed_by_success_trigger_alert

Result: PASS

The test verifies that the expected sequence produces the corresponding
alert in the sample log.

6. LIMITATIONS

- The source IP and events are fictional.
- Detection currently relies on log-line order and a cumulative
  per-IP failure count.
- The script does not enforce a time window or distinguish accounts
  when counting failed attempts.
- Alerts require analyst review and are not proof of compromise.
